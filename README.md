# Rocket Launcher

Rocket Launcher is an independently maintained Android launcher project based
on the **Lawnchair 16 (16-dev) codebase**, which itself builds on Android
Open Source Project (AOSP) Launcher3.

> **Unofficial derivative:** Rocket Launcher is not an official Lawnchair
> release and is not affiliated with, endorsed by, or sponsored by Lawnchair.
